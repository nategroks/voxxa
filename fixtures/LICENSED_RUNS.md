# Licensed test runs

Licensed songs are tested locally under the church's CCLI licence. Only the licence record and
the numbers are committed; the media, audio and lyrics never are.

One row per local `voxxa-eval` run on a licensed song (ADR-019). Never put lyrics, recognised
words, file paths under AppData, or media hashes in this file. How to make the fixture, run the
eval and fill a row: [README.md](README.md), "Making the See a Victory fixture", steps 7-8.
