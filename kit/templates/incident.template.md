# Incident note (one paragraph, numbers and labels only)

Write it the same day, blameless: what happened, not who was wrong. At most 120 words. No song words, no titles
and no names: songs by their position in the service, slides by number, times in seconds. Keep it in
`<church_root>\reports\` beside that service's report; only a numbers-only copy may leave the PC (for example as a
ticket).

Service: ____________ (date and slot)    Song: number __ in the service    When: __ s into the song

| What | Answer |

| It should have shown | slide __ |
| For how long | __ s |
| voxxa's log says | `why`: ____  gate: ____  watchdog: ____ (or "none") |
| What the person did, and when | HOLD / Back one / STOP FOLLOWING / moved the slide by hand / nothing, at __ s |
| State afterwards | following / holding / stopped (current slide held, nothing sent) / Off |
| Failure mode | number __ from the Sunday-window runbook, or "new" |

Then one paragraph that joins the rows in plain sentences, with the same numbers and nothing else.
