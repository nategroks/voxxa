Up and running in 60 seconds

1

Download & install

Grab the installer for your OS above. Double-click to install — just like Chrome or Brave.

2

Download a Whisper model

Open Voxxa, go to the Models tab, and download "Base" (142MB). Larger models = better accuracy.

3

Press the hotkey and talk

Hit Ctrl+Shift+Space (or Cmd+Shift+Space on Mac) and start speaking. Text appears wherever your cursor is.
