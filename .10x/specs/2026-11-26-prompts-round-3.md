## How to use

- **Session shape.** Each prompt is the first message of a fresh Claude Code session in the repo root, opened with
  `/10x-Team:10x-team`, exactly as the Q pack (`2026-11-11-prompts-10x-team.md:7`): read `.10x/handoff.md` and
  `.10x/status.md` first, work only inside the named phase, write the named state files, stop at the named gate.
  Steps already in `plan.md` § 4 are given here as **modification blocks**: apply the block to the plan text, then
  run the result; nothing in the plan text is re-stated unless it changes.
- **Lanes (user rule 2026-11-11).** Code steps run as two lanes off `main` (`vN/10x` with the 10x team; `vN/ponytail`
  with `ponytail` at level `full` plus `ponytail-review`, in a session that never sees the 10x output), then a
  **comparator** session that reads both PRs, picks or merges, and runs the cross-reviews and the two **verifiers**
  (A: safety lens, B: feasibility lens). Measurement, discovery, lab and close steps run as 10x plus `ponytail` +
  `ponytail-audit`. Every lane is recorded in `.10x/reviews/YYYY-MM-DD-ponytail-<step>.md` and disagreements are
  adjudicated in that file before merge. Founder steps (F5–F7) have no lanes: they are checklists the agents write
  and the founder runs.
- **State files.** Every agent step writes `decisions/<role>/church-autoadvance.md` for each named role,
  `status.md`, `handoff.md` (one line pointing the next step at what it must read) and, when it files tickets,
  `reviews/YYYY-MM-DD-<step>-tickets.md` for the founder's batch (FA-02). Review files named in a step are
  numbers-only.
- **ID scheme.** `V0…V16` as in `plan.md`; this round adds `V3e`, `V3f`, `V5a`/`V5b`, `V8-lite`, `V8b`, `V13a`,
  `V13s`, `V17`, `V18` and the founder steps `F5`, `F6`, `F7`. `FA-01…FA-45` are in `out/founder-action-items.md`;
  `FA-46…FA-72` are the adjudication's (§ 5). ADR numbers: ADR-032 is the FreeShow driver v2 (V8b); ADR-033 is
  reserved for an aligner and is written only per R5; ADR-034 (Sunday readiness, V13s) and ADR-035 (live output
  moves to FreeShow per service; two-tier app policy, V17) are proposed numbers: the writing step checks
  `.10x/adrs/` for the next free number before writing, as the Q pack rule says.
- **Sizes and cost** as `plan.md` § 2: S $3–8, M $10–25, L $25–50 at list, ×1.5 rework on L, a ponytail lane about
  doubles a code step, verifiers about +20%. The adjudication (§ 6) records the FreeShow track at about $37–95 of
