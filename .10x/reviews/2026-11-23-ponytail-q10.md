## 5. Disagreements
- **Timestamp URL:** the 10x lane's plain `http://timestamp.digicert.com` with `tsp: true` stays. DigiCert documents no https endpoint, RFC 3161 replies are signed by the TSA, and the field is used only by Tauri's own `certificateThumbprint` signing, which neither path uses. This is a recorded deviation from the task's "https if supported": it is not supported.
- **rc asset names:** the ponytail lane expected `Voxxa_0.1.0-rc.1_x64-setup.exe`. Both lanes build the version from `tauri.conf.json` (0.1.0), and the MSI needs a numeric version, so the assets are `Voxxa_0.1.0_*`. The tag run should expect the 10x names.
- **winget:** the separate `winget.yml` (published full releases only, pinned binary) beats a `release: published` trigger inside `build.yml`, which makes that file's job conditions harder to reason about.
- **`devCsp`:** the 10x lane is right to have one; without it `tauri dev` may lose Vite's injected styles and HMR.
- **SF-2 of the 10x review:** the reviewer's "map `ReleaseNotFound` to up to date" would hide GitHub outages as "up to date"; the comparator chose a neutral sentence (above).
- **Action pinning:** it applied to the 10x lane too (its own Q2-28 debt). The comparator carried it as a graft rather than a ticket, because it becomes a real risk to the updater key the day the founder adds it.
- **Still unproven in both lanes**, and not a reason to pick either: tauri-action's `releaseId` upload, `macos-15-intel`, the SignPath `@v3` inputs and the artifact configuration's wildcards, and the per-user NSIS install. The tag run (§ 10) and the first signed run prove them.

## 12. Lessons for the next step
- **Read the plugin's source before mapping its errors.** `ReleaseNotFound` meant "any non-success status", not "404"; the reviewer's natural fix would have hidden outages.
- **A pure helper is not the rule.** The listening refusal and "never at startup" were tested as functions; the verifier showed that the call sites could lose them. Test the rule where it is enforced (here, on the source text) and prove it with a mutant.
- **Empty secrets are not missing secrets.** GitHub passes a missing secret as `""`, and some tools read "set but empty" as a value. Export optional values only when they are set.
- **Two lanes found different real bugs.** The ponytail lane's real-app run found Q10-01 and Q10-02; keep the guarded real-app run in every GUI step, and record anything unexplained.
