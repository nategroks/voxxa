## 4. Replay determinism

**Test:** `src-tauri/tests/replay_determinism.rs`, part of `cargo test --features cli` on all three OSes. For every committed log (six fixtures and `tests/fixtures/voxxad/session-pd-hymns.jsonl`), two `voxxad --replay` runs in parallel must give byte-identical stdout, and replay's action lines must equal the log's own action lines byte for byte (the line content; a CRLF checkout's line ending is not part of the line). A second test checks that replay prints no start line and only v1 JSON lines.

**Re-recording (20e3301).** Before it, the test failed on exactly the four logs the Q6 handoff named. Replay printed 4/5/4/3 action lines against 1/5/4/3 recorded, differing from action 1 on (the 733c7e1 conductor's actions). They were re-recorded with `voxxa-eval --full --record` (Whisper Tiny, `--shadow`, file speed, this PC). A script compared old and new and printed counts only:

| log | input lines old = new | identical | actions old → new | start line |
|---|---|---|---|---|
| jump-be-thou-my-vision | 576 | yes | 1 → 4 | `evidence` config now stored; new relative `log` name |
| prayer-between-songs | 926 | yes | 5 → 5 | same |
| prayer-then-reprise | 482 | yes | 4 → 4 | same |
| prayer-without-pause | 343 | yes | 3 → 3 | same |

The input lines (tick, speech, window, hypothesis, and the stop status) match the Q6 handoff's counts plus the stop line. The replay table did not change, cell for cell, and `baseline.json` is unchanged. The full run printed the same four rows.

**Proof by mutation:**
- Old logs: check 1 fails (above).
- Replay printing the wall time in ns: check 2 fails on all seven logs ("two replays differ"). Reverted.
- Unmutated: passes in 71-104 s (debug, Windows; 104 s while the full eval ran beside it).

**Across OSes:** the test runs on each OS's own checkout, which covers CRLF (Windows) and LF (Linux, macOS). Verifier A in Q6 had already shown that replay is byte-identical across CRLF and LF checkouts. Q7 does not compare outputs between OSes inside one test.
