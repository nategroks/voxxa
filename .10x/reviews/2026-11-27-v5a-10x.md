## 4. Step 9, the one Rust change (`src-tauri/src/importers/txt.rs`, `src-tauri/src/aligner/mod.rs`)

Built as plan V5 step 9 and spec § 4.5 describe, with these readings stated:

1. **Sections.** A section label line starts a `Section { kind, slides }` and covers every slide that follows it up to
   the next label ("the label plus the slides it covers, starting at its first slide index"); slides before the first
   label are in no section; a label followed by no slide before the next label (or the end) is dropped
   (`sections.retain`). The label stays off the slide text, as before. `check_sections` passes on the result (the test
   calls it).
2. **Label → `SectionKind`, "as ADR-016's parser does":** `verse` → Verse, `chorus` and `refrain` → Chorus, `bridge` →
   Bridge, `tag` → Tag, and every other label the importer already accepted (`pre-chorus`, `pre chorus`, `prechorus`,
   `intro`, `outro`, `ending`, `interlude`) → Other, exactly as serde reads `sections[].kind` (`#[serde(other)]`).
   The plan's `[UNVERIFIED]` is resolved: `SectionKind` has a value for every accepted label, so the "unmapped label is
   dropped" branch never fires; a line the importer does not accept as a label stays slide text, as before.
3. **Credit slide.** A slide whose first line (after label stripping) starts with `Credit:` (exact case, as the spec
   writes it) gets `kind: Some("credit")`; the `Credit:` line stays on the slide, because the same text is pasted into
   the presentation app (ADR-026 § 1). **Reading recorded:** the credit slide belongs to no section (it ends the open
   one); a credit is not part of a sung part, and ADR-022 § 4 steps past it at song end. The plan does not say either
   way; `credit_slide_kind_detected` pins this reading.
4. **`Slide.kind` is `Option<String>`**, `#[serde(default, skip_serializing_if = "Option::is_none")]`: 2 code lines,
   written only when set, read as any string (forward compatible). Not an enum: an enum would not fit the 3-line
   allotment, and V11's credit gate is the first reader; it may type it then.
5. **`Slide::new(id, text)`** (9 lines in `aligner/mod.rs`): the plain lyric slide; see § 3 for why.
